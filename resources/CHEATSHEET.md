# Aide-mémoire

| But | Commande |
|---|---|
| État Git | `git status` |
| Recevoir | `git pull --ff-only` |
| Nouvelle branche | `git switch -c nom` |
| Voir les changements | `git diff` |
| Enregistrer | `git add fichier && git commit -m "Message"` |
| Publier | `git push -u origin nom` |
| Où suis-je ? | `pwd` |
| Lister | `ls -lah` |
| Soumettre | `sbatch script.slurm` |
| Jobs actifs | `squeue -u "$USER"` |
| Historique | `sacct -X --starttime today` |
| Annuler | `scancel JOB_ID` |
| Nœuds | `sinfo` |
| Activer Python | `source .venv/bin/activate` |
