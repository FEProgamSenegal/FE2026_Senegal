# Glossaire

- **Dépôt** : projet suivi par Git.
- **Commit** : instantané identifié et commenté.
- **Branche** : ligne de travail indépendante.
- **Pull request** : proposition de fusion sur GitHub.
- **SSH** : protocole de connexion distante sécurisée.
- **HPC** : calcul haute performance.
- **Head node** : nœud de connexion et d'orchestration.
- **Compute node** : machine exécutant un calcul.
- **Slurm** : planificateur de jobs.
- **Job** : unité de travail soumise au planificateur.
- **Partition** : file de ressources Slurm.
- **EMOD** : logiciel de modélisation épidémiologique individuelle.
- **Graine** : valeur initialisant un générateur pseudo-aléatoire.
- **Environnement virtuel** : installation Python isolée d'un projet.
