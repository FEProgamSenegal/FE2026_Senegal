# Projet final — Expérience EMOD reproductible

En binôme, concevez une petite expérience de paludisme inspirée d'un contexte sénégalais, sans prétendre produire une recommandation sanitaire réelle.

## Exigences

- question clairement formulée ;
- hypothèses et limites ;
- dépôt Git avec branche et pull request ;
- job Slurm reproductible ;
- au moins 5 graines aléatoires ;
- ressources et temps documentés ;
- figure comparant les répétitions ;
- README permettant à un autre groupe de relancer l'expérience ;
- aucune donnée sensible et aucune conclusion de santé publique non justifiée.

## Livrables

Code, configuration, script Slurm, fichier de versions, résultats synthétiques, figure, rapport de deux pages et présentation de cinq minutes.

## Barème /100

Git et reproductibilité 20 ; usage sûr du HPC 20 ; exécution EMOD 25 ; analyse et limites 20 ; documentation et présentation 15.
