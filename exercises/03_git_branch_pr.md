# Exercice 3 — Branche et pull request

Créez `etudiant/IDENTIFIANT`, ajoutez vos réponses sans modifier celles d'un autre étudiant, faites un commit précis, poussez la branche et ouvrez une pull request. Demandez une revue à un camarade et corrigez au moins un commentaire.

Critères : branche correcte, historique lisible, aucun secret, conflit évité, description de PR complète.
